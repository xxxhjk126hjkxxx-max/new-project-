# دفتر الحضور المحلي بالـ QR — IUA

الليدر ينشئ كوداً نصياً لكل طالب. الطالب يدخله في قسم الطالب لتوليد رمز QR على هاتفه. عند المسح يطابق هاتف الليدر الكود مع الطالب في قاعدة بياناته المحلية، من دون رفع صور أو إرسال سجلات إلى خادم.

## التشغيل الأول

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

- **هاتف الليدر:** افتح `/` من متصفح حديث. يلزم عنوان **HTTPS بشهادة يثق بها الهاتف**، أو `localhost` إذا كان الخادم على الجهاز نفسه، لتفعيل الكاميرا وحفظ التطبيق للعمل بلا اتصال. عنوان الشبكة المحلية بصيغة `http://192.168...` لا يكفي. يمكن تقديم ملفات التطبيق أول مرة من خادم HTTPS على الشبكة المحلية؛ لا يلزم خادم على الإنترنت. انتظر ظهور **«جاهز للعمل بلا إنترنت»**، ثم أضف الصفحة إلى الشاشة الرئيسية إن أردت.
- **هاتف الطالب:** افتح `/student` مرة واحدة وانتظر رسالة الجاهزية، أو انقل الملف العام `iua-student-offline.html` إلى الهاتف من زر **«تنزيل صفحة الطالب للعمل بلا إنترنت»**. الملف واحد لكل الطلاب ولا يتضمن أكواداً شخصية. افتحه في متصفح يشغّل JavaScript؛ معاينة المرفقات أو مدير الملفات قد لا تشغّل الصفحة التفاعلية. لا يحتاج الطالب إلى رابط خاص أو إلى إنشاء حساب.
- **تجربة سريعة على الكمبيوتر:** افتح `http://127.0.0.1:5000`. في معاينة Arena يُفضّل فتح التطبيق في تبويب مستقل عند استخدام الكاميرا، ثم منح إذن الكاميرا.

## الاستخدام بعد فصل الاتصال

1. من **الطلاب** أضف الطالب ثم اختر **كود الطالب**. انسخ الكود النصي أو أعطه للطالب مباشرة.
2. في **قسم الطالب** يُدخل الطالب الكود ويضغط **توليد رمز QR**.
3. أنشئ محاضرة، واخترها في **مسح الحضور**، ثم وجّه كاميرا هاتف الليدر إلى رمز الطالب. يوجد خيار قراءة صورة رمز كبديل عند تعذّر تشغيل الكاميرا.
4. يسجّل التطبيق الوقت محلياً ولا يسجّل الطالب مرتين للمحاضرة نفسها. يمكن مراجعة الحاضرين والغائبين وتنزيل تقرير CSV.

## أين تُحفظ البيانات؟

| البيانات | مكان الحفظ |
| --- | --- |
| الطلاب وأكوادهم والمحاضرات وسجلات الحضور | قاعدة **IndexedDB** على هاتف الليدر، في نفس المتصفح وعنوان التطبيق. |
| كود الطالب بعد توليد الرمز | مساحة المتصفح المحلية على هاتف الطالب إذا سمح بها المتصفح. يمكن مسحه من صفحة الطالب؛ الرمز يعاد توليده من الكود ولا يُرفع إلى الخادم. |
| واجهتا التطبيق ومكتبات QR | نسخة على الجهاز تحفظها **Service Worker** لتعمل الصفحات دون اتصال بعد التحميل الأول. |
| ملف CSV | يُنشأ في المتصفح ويُنزّل إلى الجهاز. |

لا توجد مزامنة تلقائية بين الهواتف. لا تعتمد على التصفح الخاص، ولا تمسح بيانات التطبيق؛ امسح رمز الطالب من هاتفه فقط عند الحاجة. صدّر التقارير قبل تغيير الجهاز أو المتصفح. الكود ثابت لهذا الطالب: لا تشاركه مع طلاب آخرين، لأن نسخة منه أو من رمز QR تكفي لتقديمه مرة أخرى؛ لا يتحقق التطبيق من هوية حامل الرمز.

## النسخة السابقة

ما زالت نسخة Flask/SQLite السابقة متاحة عبر `/login` لمن يستخدم بياناتها. قواعد البيانات مستقلة؛ لا تُنقل سجلاتها تلقائياً إلى النسخة المحلية. لا تنشر النسخة السابقة ببيانات الدخول التجريبية: إذا نشرتها فاضبط `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`SECRET_KEY` و`COOKIE_SECURE=true`، واستخدم مسار `DATABASE_PATH` على قرص دائم.

الوثائق التاريخية للنسخة السابقة: [خريطة حركة البيانات](docs/attendance-data-map.png) · [خريطة الكود التفاعلية](docs/architecture/graph.html).

لاختبار مسارات النسخة المحلية والملف المستقل: `python -m unittest discover -s tests -v`.
