# نظام حضور الطلاب بالـ QR — IUA

تطبيق ويب عربي RTL لإدارة الطلاب والمحاضرات وتسجيل الحضور عبر QR، بتصميم مستوحى من ألوان الشعار المرفق (الأزرق والأخضر). الطلاب لا يحتاجون إلى حساب.

## التشغيل المحلي
1. ثبّت Python 3.10 أو أحدث.
2. من مجلد المشروع نفّذ:
   ```bash
   python -m venv .venv
   # Windows: .venv\\Scripts\\activate
   # macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   python app.py
   ```
3. افتح `http://127.0.0.1:5000` وسجّل الدخول ببيانات التجربة: المستخدم `admin`، كلمة المرور `admin123`.
4. أضف الطلاب، أنشئ محاضرة، ثم اختر «مسح الحضور». على الهاتف يجب فتح الموقع عبر HTTPS والسماح باستخدام الكاميرا. ويمكن استخدام إدخال رقم الطالب يدوياً للاختبار.

## إعداد الدخول والنشر
قبل النشر، عيّن متغيرات البيئة `ADMIN_USERNAME` و`ADMIN_PASSWORD` لقيم خاصة بك، و`SECRET_KEY` إلى قيمة طويلة عشوائية. فعّل `COOKIE_SECURE=true` عند استخدام HTTPS. لا تستخدم بيانات التجربة في موقع عام.

يمكن نشر التطبيق على Render كـ Web Service من هذا المستودع، مع Build Command: `pip install -r requirements.txt` وStart Command: `gunicorn app:app`. أضف المتغيرات أعلاه من إعدادات الخدمة، واختر قرصاً دائماً (Persistent Disk) لمسار قاعدة البيانات `/var/data/attendance.db`، ثم أضف `DATABASE_PATH=/var/data/attendance.db`. بدون قرص دائم قد تضيع قاعدة SQLite عند إعادة تشغيل الخدمة. تحقّق من خطة الاستضافة الحالية وتكلفتها قبل النشر؛ هذا المستودع لا ينشئ خدمة استضافة أو رابطاً عاماً بنفسه.

## ملاحظة أمنية مهمة
هذا إصدار أولي مناسب للتجربة والاستخدام المحدود. رموز QR تحمل رقم الطالب، لذلك شاركها بحذر. قبل استخدامه لبيانات جامعية فعلية، استخدم كلمة مرور قوية ومفتاح جلسة عشوائياً، ونسخاً احتياطية لقاعدة البيانات، واستضافة دائمة آمنة. لا تضع كلمات المرور أو الأسرار في ملفات المستودع.
