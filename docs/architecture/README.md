# خريطة الكود — نظام حضور الطلاب IUA

افتح [`graph.html`](graph.html) في المتصفح. ابحث باسم دالة أو ملف، ثم اضغط على العقدة لعرض ملفها ورقم السطر والعقد المرتبطة بها. مرّر المؤشر فوق السهم لرؤية نوع العلاقة. تعمل الصفحة دون اتصال بالإنترنت.

## تتبّع تسجيل الحضور

| الطبقة | مسار التنفيذ |
| --- | --- |
| المتصفح | في [`attendance.html`](../../templates/attendance.html#L9)، يستدعي مسح الكاميرا `onScan()` الدالة `recordAttendance()`، ويصل إليها الإدخال اليدوي أيضاً. ترسل الدالة `lecture_id` و`qr_data` إلى `POST /api/scan`. |
| خادم Flask | [`api_scan()`](../../app.py#L237) محميّ بـ `login_required()`، ويستخرج رقم الطالب عبر `student_number_from_qr()` ويتحقق من وجود الطالب والمحاضرة قبل الحفظ. |
| قاعدة البيانات | يكتب المسار في جدول [`attendance`](../../app.py#L58) في SQLite. يربط مفتاحان خارجيان السجل بالطالب والمحاضرة، ويمنع القيد `UNIQUE(lecture_id, student_id)` تسجيل الطالب مرتين للمحاضرة نفسها. |
| التقارير | تقرأ [`reports()`](../../app.py#L258) سجلات الحضور وتحدد الغائبين، بينما تنشئ [`export_excel()`](../../app.py#L273) ملف XLSX باستخدام `openpyxl`. |

## ملفات الخريطة

- [`graph.json`](graph.json): العقد والعلاقات مع مواقعها في الكود؛ قابل للاستعلام بواسطة Graphify.
- [`GRAPH_REPORT.md`](GRAPH_REPORT.md): تقرير Graphify الآلي عن أكثر العقد اتصالاً والمجموعات المكتشفة.

استُخرجت علاقات Python باستخدام Graphify بوضع `--code-only` محلياً، ثم أُضيفت العلاقات المباشرة من قوالب Jinja وكود الماسح المضمّن واستعلامات SQLite. لا تتضمن الخريطة بيانات الطلاب أو سجلات الحضور الفعلية.

مثال على استعلام من جذر المستودع (بعد تثبيت `graphifyy`):

```bash
graphify path recordAttendance 'SQLite · attendance' --graph docs/architecture/graph.json
```
